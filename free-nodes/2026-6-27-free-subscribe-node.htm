引言：数字时代的网络困境与解决方案

在信息自由流动的今天，全球互联网却呈现出割裂的态势。许多地区的网络审查机制（如中国的"防火长城"）将大量国际网站和服务隔绝在外，严重影响了人们获取信息、学术交流和商业往来的效率。面对这一困境，传统VPN虽然有效，但存在速度慢、易被封锁、收费昂贵等问题。而修改hosts文件这一古老而经典的技术手段，正以其轻量、快速、无需第三方软件的特性重新进入大众视野。

第一章：hosts文件的前世今生

1.1 什么是hosts文件？

hosts文件是互联网发展早期的产物，可以追溯到ARPANET时代。这个纯文本文件存在于所有现代操作系统中，其本质是一个本地域名解析（DNS）数据库。当你在浏览器输入"www.google.com"时，系统会首先查询hosts文件，若找到对应记录则直接访问指定IP；若未找到，才会向公共DNS服务器发起查询请求。

1.2 为什么修改hosts能突破封锁？

网络审查系统通常通过DNS污染（返回错误的IP地址）或IP封锁来实现访问限制。通过手动在hosts文件中添加正确的"域名-IP"映射，相当于绕过了被污染的DNS查询环节，直接从本地指定目标服务器的真实IP地址。这就如同在城市交通管制时，你手握一张标注了所有秘密通道的地图。

Windows系统

位于C:\Windows\System32\drivers\etc\hosts。注意：

路径为/etc/hosts。需注意：

- 建议使用终端编辑

macOS/Linux用户：

步骤三：添加有效映射
格式规范：
IP地址 域名 # 注释 实用示例：

步骤四：刷新DNS缓存
Windows:

FAQ

Sing-box 如何按域名分流优化浏览器流量？
Sing-box 可通过规则匹配域名，将浏览器流量分配到最优节点。结合策略组，可保证网页访问速度和稳定性，同时优化视频和游戏等其他流量，提高整体网络体验。
Mihomo 是什么项目？
Mihomo 是 Clash Meta 的继任版本，也被称为 Clash.Meta 的社区分支。它优化了性能，支持更多协议如 Hysteria2、TUIC 等，同时提供更灵活的规则匹配系统，是目前非常流行的分流代理核心。
Sing-box 如何实现流量精细分流？
通过定义 routing 规则和策略组，Sing-box 可以根据域名、IP、端口或协议类型精细分流流量。例如视频走高速节点，网页走备用节点，实现流量优化和网络加速。
Mihomo 的 Rule-Set 与 Clash Premium 是否兼容？
Mihomo 完全兼容 Clash Premium 的 Rule-Set 格式，支持相同的远程规则订阅与策略分组。用户可直接迁移原 Clash 配置，无需额外修改或转换。
Clash 是什么？它主要有什么用途？
Clash 是一个跨平台的代理客户端，支持多种代理协议，如 Vmess、Vless、Trojan 和 Shadowsocks 等。它主要用于分流管理、网络代理和科学上网，用户可以通过配置文件灵活控制网络流量，实现不同网站或应用走不同代理。
V2Ray 如何隐藏真实 IP？
通过启用 TLS、Reality 或 WebSocket + CDN 转发，V2Ray 可有效隐藏真实服务器 IP。这样外部监测只能看到中转节点，从而提升匿名性与安全性。
如何检查 Clash 连接失败的日志以定位问题？
打开 Clash 的日志面板或查看配置目录下的 log 文件，观察报错信息如 DNS 解析失败、节点拒绝连接或 TLS 握手错误。根据关键字（例如 timeout、refused、certificate）逐项排查并比对服务器配置。
Mellow 的 TUN 模式与系统代理有何区别？
TUN 模式拦截系统 IP 层流量，实现全局代理，而系统代理通常只影响支持代理的应用。TUN 更适合游戏、视频和全局科学上网场景，保证所有流量通过节点，提高稳定性和速度。
Matsuri 如何通过节点测速选择最优线路？
Matsuri 会定期测速节点延迟和丢包率，结合策略组自动选择延迟低、稳定性高的节点。这样可以提升网页、视频和游戏访问速度，减少掉线和卡顿，优化整体体验。
Mellow 支持哪些平台？
Mellow 是基于 Electron 的跨平台代理工具，支持 Windows、macOS 和 Linux。它通过 TUN 模式接管全局流量，并支持 Clash 规则和订阅格式，非常灵活。
